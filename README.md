## Bugs Reported

1. Unable to remove uploaded photo/video.
2. Generic "Something went wrong" error message.
3. Missing option to replace uploaded media.
4. Limited user feedback during upload.
5. Media upload workflow lacks proper user control.

## Recommendations

- Improve media upload functionality.
- Add remove/replace options for uploaded files.
- Display meaningful error messages.
- Improve loading indicators.
- Continue cross-browser and accessibility testing.
